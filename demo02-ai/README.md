# demo02-ai

基于 `demo01-quickstart` 的工具链初始化：Next.js 16 + React 19 + Tailwind CSS 4 + shadcn/ui。

UI 基础件（button、input）来自 demo01，可直接使用；demo01 中的路由/API 学习页面未复制。

## Getting Started

```bash
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

## 初始化说明

依赖使用 `npm ci --offline` 从本机 npm 缓存安装，未重新下载。
